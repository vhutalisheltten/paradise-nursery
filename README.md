# e-plantShopping

Paradise Nursery is an e-plantShopping React and Redux application for browsing indoor houseplants,
adding them to a cart, and adjusting quantities before checkout.

## Features

- Landing page with a plant nursery background image, company name, company description, and
  Get Started link.
- Product listing page with six unique houseplants grouped into three categories.
- Redux-powered shopping cart with dynamic header quantity, per-item totals, quantity controls,
  delete buttons, and total cart amount.
- GitHub Pages-friendly routing through hash URLs.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy the generated `dist` folder to GitHub Pages after pushing this project to a public
GitHub repository.
